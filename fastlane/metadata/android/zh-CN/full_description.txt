台风眼（TyphoonEye）是一款轻量、开源的 Android 实时台风路径与气象预警应用。

功能：
• 基于 MapLibre 的交互式地图展示台风（实时数据需填写自己的 API 密钥，见下文）
• 历史路径、预报路径，以及七/十/十二级分象限风圈
• 可选基于距离的紧急预警（需定位权限）
• Material Design 3、动态取色、深浅色与多语言
• 未填写 API 密钥时提供明确标注的演示模式（虚构示例台风）

网络说明：
实况数据来自第三方气象接口（和风 / 聚合）。F-Droid 版不内置任何密钥：如需实时数据，请申请自己的和风天气 API 密钥（API Key + 账号专属 API Host）或聚合数据 API 密钥，并在「设置 → 自定义数据源密钥」中填写。密钥只保存在本机，不上传、不写入日志、不进入备份，只发送给对应的数据服务商。未填写密钥时不显示实时台风数据：应用会说明这一点，提供密钥设置入口，以及可选的演示模式（虚构示例台风，标注「示例数据，非真实台风」）。中国大陆底图可选高德瓦片。不含广告与统计分析。

本应用并非官方气象应用。紧急情况下请务必以当地气象部门发布为准。

F-Droid 构建通过 F-Droid 客户端更新（不含 GitHub 侧载更新）。
